# Что из MineColonies есть в этом срезе

Java-мод [MineColonies](https://github.com/ldtteam/minecolonies) на Horizon не запускается: Horizon не исполняет Forge и Fabric. Этот репозиторий — отдельная реализация той же петли основания. Имена блоков хижин совпадают с реестром MineColonies, чтобы позже можно было подставить схематики. Код, модели и текстуры Java-мода сюда не копировались.

| Система MineColonies | В 0.1 | Дальше |
|---|---|---|
| Лагерь снабжения и основание колонии | Предмет ставит ратушу и стартовый склад | Выбор стиля, припасы из сундука лагеря |
| Ратуша, склад, дом, хижины работ | Чертежи из досок, булыжника, стекла и двери | Схематики и `native_structure_template` |
| Строитель кладёт блоки | Один блок за такт работы, оплата со склада | Очередь запросов, строительные леса, несколько строителей |
| Жители и профессии | Двое безработных сразу; builder, farmer, lumberjack, miner, courier, guard | Навыки, жильё по кроватям, дети, имена из списка мода |
| Исследования | Шесть узлов, каждый открывает одну хижину | Дерево университета |
| Склад | `/colony deposit` и `withdraw`, обычные стаки | Запросы, курьер таскает из сундуков, интерфейс склада |
| Рейд | Разбойники, стража снимает им запас прочности | Волны варваров, ворота, башни как в моде |
| Приват | Радиус 64 от двери, чужие не ломают блоки | Флаги участков, права жителей |
| Интерфейс | Три строки справа сверху и чат `/colony` | Экраны хижин и книга исследований |
| Счастье | Число на табличке, еда и таверна | Потребности, болезни, украшения |

Сохранение — `minecolonies/colony.json` в папке мира. Идентификаторы сущностей в файл не пишутся: после загрузки `/colony recall` вызывает жителей заново.
